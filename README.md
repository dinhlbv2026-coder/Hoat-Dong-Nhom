# Hoạt Động Nhóm

Ứng dụng web một file (`index.html`) để theo dõi hoạt động nhóm tư vấn viên: đăng ký hội nghị theo nhóm, khách mời và người đi kèm, check-in, số chốt, theo dõi khách sau hội nghị, dự báo và xuất báo cáo Excel/ảnh.

- Mở `index.html` bằng trình duyệt là dùng được, không cần cài đặt.
- Dữ liệu lưu trong trình duyệt của người dùng (localStorage), không gửi lên máy chủ.
- Bản công khai không kèm dữ liệu tư vấn viên hay khách hàng. Danh sách TVV nhập trong mục Quản lý.
